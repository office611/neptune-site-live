## Campaign Design Principles

This campaign corrects every flaw from the five previous ads and builds a unified, premium system.

| Old ads | This campaign |
|---------|---------------|
| Price as primary message | Value and quality as primary message |
| Yellow discount callouts | Copper EOFY badge — understated |
| No Neptune logo | Logo on every creative |
| No trust credentials | WaterMark · VIC Licensed · 7-Year Warranty on every ad |
| Fear-based tone ("TOXIC") | Calm confidence — curiosity and aspiration |
| Bright electric blue | Neptune Deep (#0B1E3D) throughout |
| Heavy condensed caps | Poppins — clean, weighted, premium |
| Inconsistent editing | One colour system, one overlay language, one layout rhythm |
| Price as CTA closer | "Book Your Free Water Test →" as CTA closer |

## EOFY Offer Language (Approved Phrasing)

The offer must remain secondary. These are the only approved ways to reference it:

| Format | Text |
|--------|------|
| EOFY badge (small) | "EOFY Upgrade Event" |
| EOFY badge (specific) | "Exclusive May Installation Offer" |
| EOFY badge (booking) | "Now Booking May Installations" |
| EOFY badge (offer) | "EOFY Offer Available" |
| EOFY badge (month) | "May Installation Offer" |
| Offer line (Ad 10 only) | "20% off whole home filtration, exclusively this May." |

**Rules:**
- Never larger than body-sm size relative to the headline
- Never in the primary headline position
- Always secondary to the brand message
- Use the EOFY badge treatment (bordered, copper, small-caps)

## Production Checklist (Before Publishing)

- [ ] Every ad carries the Neptune logo (white version, top-left — except Ad 10 centred)
- [ ] Trust bar present: WaterMark Certified · VIC Licensed & Insured · 7-Year Warranty
- [ ] No price shown anywhere as the primary visual
- [ ] No fear-based language ("TOXIC", "DANGER", "STOP DRINKING")
- [ ] No bright electric blue backgrounds (all dark tones use Neptune Deep #0B1E3D)
- [ ] EOFY reference is secondary in size to the main headline
- [ ] CTA is "Book Your Free Water Test" (or variant) — not "Shop Now", "Learn More"
- [ ] All images are real Neptune product photography
- [ ] Copper rule lines at 40–55% opacity (subtle, not dominant)
- [ ] All text is Poppins — no mixed typefaces
