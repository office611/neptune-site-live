# Neptune Filtration — Product & Service Catalogue

## Core Product: Neptune 5-1-1 Micron Whole-Home System

### What It Is
A 3-stage whole-home water filtration system installed at the mains water entry point.
Filters all water throughout the home — every tap, every shower, every appliance.

### System Specs

| Spec | Detail |
|------|--------|
| Housing size | 20" standard |
| Filtration stages | 3 (5–1–1 micron) |
| Stage 1 | Pleated sediment filter — 5 micron |
| Stage 2 | Scale reduction carbon block — 1 micron |
| Stage 3 | Coconut carbon block — 1 micron |
| Certification | WaterMark (AS 3497) |
| Warranty | 7-year workmanship |
| Installation type | Whole-home mains connection |
| Install time | Under 2 hours |
| Requires plumber | Installed by licensed VIC plumber |
| Filter replacement interval | Every 12 months |

### What Each Stage Removes

**Stage 1 — Pleated Sediment Filter (5 micron)**
- Rust, dirt, and sediment
- Fine particles from older pipes
- Physical debris in supply water

**Stage 2 — Scale Reduction Carbon Block (1 micron)**
- Chlorine (taste + odour)
- Scale-forming minerals (calcium, magnesium)
- Reduces hardness deposits on appliances and glass

**Stage 3 — Coconut Carbon Block (1 micron)**
- Pesticides and herbicides
- VOCs (volatile organic compounds)
- Heavy metals including lead and mercury
- Disinfection by-products (chlorine reaction compounds)
- Remaining chlorine and chloramine traces

### What Changes After Installation (Customer-Facing Benefits)

1. **Drinking water** — No chlorine taste or smell. Drink straight from any tap.
2. **Skin & hair** — Softer skin, less dryness. Some customers report eczema and hair improvements.
3. **Shower & glass** — Less scale, no pool smell. Bathroom stays cleaner, longer.
4. **Appliances** — Reduced mineral buildup extends dishwashers, kettles, washing machines.
