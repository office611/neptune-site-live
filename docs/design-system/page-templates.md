# Neptune Filtration — Reusable Page Templates

**Status:** Documentation only. No live changes.
**Purpose:** Blueprint structures for any new page. Each template specifies:
- Purpose and funnel stage
- Section order and content
- Component types
- CTA and trust signal placement
- Mobile behaviour

Use these as wireframe-level layouts. Apply the design system for visual specs.

## Component Placement Rules (All Templates)

### Trust Signals — Where They Go

| Component | Always | Optional |
|-----------|--------|----------|
| Phone 03 9122 5243 | Header, footer | Near form |
| Email office@neptunefiltration.com.au | Footer | Pre-appt contact section |
| WaterMark Certified AS 3497 | Trust bar (hero + footer) | Near CTA |
| VIC Licensed & Insured | Trust bar (hero + footer) | Near CTA |
| 7-Year Workmanship Warranty | Trust bar (hero + footer) | Product section |
| "No obligation" | Near booking CTA | In hero subhead |
| "Approximately 30 minutes" | Near booking CTA | Hero |

### CTA Placement Rules

1. **First appearance:** Always above the fold in the hero
2. **Second appearance:** After the first content section (before they scroll too deep)
3. **Third appearance:** In the dedicated form/closing section
4. **Never:** Two competing primary CTAs side-by-side in the same section

### Footer — Every Page

The footer is never optional. Every page uses the full footer structure documented
in the design system. The only exception is landing pages with intentionally minimal footers —
but even those retain the phone number, email, and trust bar.
