# Email Flow — Post-Install Upsell & Retention

## Trigger
System installed. Customer marked "active" in CRM.

## Flow Overview

```
Day 1   → Thank you + what to expect
Day 7   → Check-in + filter care tips
Day 30  → Satisfaction check + review request
Day 60  → Upsell — add RO or softener
Day 330 → Annual maintenance reminder
```
